# Flutter Design Patterns — بالمصري

دليل مذاكرة عملي للـ Design Patterns في Flutter و Dart، مكتوب بالعامية المصرية مع المصطلحات بالإنجليزي.

**الموقع:** https://dobydragon.github.io/flutter-design-patterns/

## المحتوى

| الصفحة | فيها إيه |
|---|---|
| `guide.html` | 11 pattern أساسي (ما هو، المشكلة، بيشتغل إزاي، امتى تستخدمه، عيوبه، إجابة الـ interview، أسئلة متابعة)، و 10 مقارنات، وأنماط لسه هتتعلمها |
| `examples.html` | 14 مثال Dart صافي، كل واحد فيه BEFORE و AFTER (الملفات نفسها في `examples/`) |
| `interview.html` | أسئلة Junior → Senior بإجابة إنجليزي وفكرة بالمصري |
| `roadmap.html` | خطة مذاكرة على 4 مراحل + جدول زمني |

## تشغيل الأمثلة

```bash
dart run examples/07_strategy_checkin_methods.dart
```
